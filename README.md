# investmentcareer

双击 `启动财报主页.command`，自动生成索引并在浏览器打开本地 `docs/index.html`。

**关闭启动窗口后，已收录财报数量保持不变，仍可阅读、刷新或重新打开主页。** 数据保存在项目的轻量摘要 `docs/components-meta.js`、全文索引 `docs/components-snapshot.js` 与按篇正文缓存中，主页不依赖本地 HTTP 服务。

将 `.html` 或 `.htm` 文件放入 `docs/Components`。启动窗口开启时每 2 秒检查文件变动并保存索引，主页每 10 秒读取最新索引，也可点击「刷新已保存索引」。新增、修改和删除会同步到主页。

关闭启动窗口仅停止自动收录。之后添加文件，重新双击启动入口即可收录；也可在项目目录运行 `python3 build_snapshot.py` 手动重建索引。平时可直接双击 `docs/index.html` 阅读已保存财报。

首页从标题、正文、侧边栏和 KPI 卡片提取公司信息、摘要与全文搜索索引。首页样式已编译为本地 `docs/portal.css`，打开首页无需等待样式 CDN；站内详情阅读器使用 `docs/vendor/` 中的样式与图表脚本，字体在后台加载；直接打开或下载的财报原件仍保留原来的外部依赖。

首页先显示 10 家公司，再后台同步轻量摘要，不解析全部财报 HTML，也不在打开时读取整库全文。全文索引在首次搜索或导出时按需加载；自动同步先检查 `components-version.js`，版本变化时只更新摘要。摘要、全文和按篇缓存使用版本号复用浏览器缓存。

`build_snapshot.py` 同时生成 `docs/.report-cache/` 按篇缓存文件。打开财报后预加载相邻两篇；悬停、键盘聚焦或触摸阅读入口也会按需预加载。最多同时加载两篇、内存保留六篇；预加载不可用时仍直接打开 Components 原文件。生成文件会保存在磁盘，关闭启动窗口不影响阅读。

详情页优先加载当前报告，不等待全库索引或本地导入记录；正文通过同源内嵌文档同步亮暗主题。轻量摘要由 `build_snapshot.py` 自动生成，新收录报告仍使用原来的收录流程。
